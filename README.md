# Метод Гаусса для решения систем линейных уравнений

Этот проект реализует метод Гаусса для решения систем линейных уравнений с возможностью генерации случайных систем для тестирования.

## Требования

- C++17 совместимый компилятор (GCC 7.0 или новее)
- Библиотека Eigen3
- Make
- GTest (для запуска тестов)



## Сборка проекта

```bash
# Сборка основного проекта
make

# Сборка и запуск тестов
make test

# Очистка
make clean
```

## Использование

Программа поддерживает два режима работы:

1. Решение системы уравнений из CSV файла:
   ```bash
   ./main input.csv output.csv
   ```

2. Генерация случайной системы уравнений:
   ```bash
   ./main --generate N SEED output.csv
   ```
   где:
   - N - размер системы (количество уравнений)
   - SEED - начальное значение для генератора случайных чисел
   - output.csv - файл для сохранения сгенерированной системы

### Формат CSV файлов

#### Входной файл
- Каждая строка представляет одно уравнение
- Последний столбец - правая часть уравнения
- Остальные столбцы - коэффициенты при неизвестных
- Разделитель - запятая

Пример:
```
2,1,3,10
1,3,2,11
3,2,1,12
```

#### Выходной файл
- Одна строка с решением системы
- Значения разделены запятыми
